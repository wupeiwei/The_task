# 双板 CAN 通信协议 v2

## 总览

| 项目 | 约定 |
|---|---|
| 总线 | CAN1，1Mbps，标准帧（11bit ID），DLC=8 |
| 字节序 | 小端（低字节在前，与 STM32 一致） |
| 校验 | CRC-8（多项式 0x07，初值 0x00，不反射，不异或输出），覆盖数据区 [0-6]，结果放 [7] |
| 发送周期 | 控制帧 5ms（云台），反馈帧 10ms（底盘） |

## ID 分配

| ID | 方向 | 含义 |
|---|---|---|
| 0x101 | 云台 → 底盘 | 控制帧 |
| 0x201 | 底盘 → 云台 | 反馈帧 |

## 0x101 控制帧（云台 → 底盘）

| 字节 | 字段 | 类型 | 说明 |
|---|---|---|---|
| [0-1] | 电机目标速度 | int16 | 来自摇杆 Y 轴，负值=反转 |
| [2-3] | 舵机目标转速 | int16 | 来自摇杆 X 轴，底盘 OLED 显示用 |
| [4] | 序号 | uint8 | 0~255 循环，发一帧 +1，检测丢帧 |
| [5] | 云台状态 | uint8 | 位定义见下表 |
| [6] | 协议版本 | uint8 | 当前 = 1 |
| [7] | CRC-8 | uint8 | 覆盖 [0-6] |

云台状态 [5]：位0 = 舵机在线（云台已使能 PWM 输出），位1 = 板间通信正常，其余保留。

## 0x201 反馈帧（底盘 → 云台）

| 字节 | 字段 | 类型 | 说明 |
|---|---|---|---|
| [0-1] | 指令速度回显 | int16 | 收到的电机目标速度原样返回，验证指令链路 |
| [2-3] | 电机实际转速 | int16 | 编码器实测 |
| [4] | 序号 | uint8 | 底盘发送计数 |
| [5] | 底盘状态 | uint8 | 位定义见下表 |
| [6] | 协议版本 | uint8 | 当前 = 1 |
| [7] | CRC-8 | uint8 | 覆盖 [0-6] |

底盘状态 [5]：位0 = 电机在线（能读到编码器反馈），位1 = 板间通信正常，位2 = 电机异常（收到目标≠0 且实际转速长时间≈0），其余保留。

## 状态判定语义

| 状态 | 判定依据 | 维护方 |
|---|---|---|
| 舵机在线 | 云台已使能舵机 PWM 输出（软标志，舵机无反馈） | 云台 |
| 电机在线 | 底盘能读到编码器计数反馈 | 底盘 |
| 电机异常 | 目标≠0 且实际转速长时间≈0（堵转/掉线） | 底盘 health 逻辑 |
| 板间通信正常 | 超时（约定 100ms）没收到对方帧则置异常 | 双板各自维护 |

## CRC-8 规范

- 多项式：0x07（x^8 + x^2 + x + 1）
- 初值：0x00，无输入/输出反射，最终值不异或
- 计算范围：数据字节 [0] ~ [6]，结果写入 [7]
- 实现：位运算逐字节处理即可（无需查表）
